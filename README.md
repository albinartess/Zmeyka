# Змейка

[Открыть игру в браузере](https://albinartess.github.io/Zmeyka/)

Игра без установки. Управление: стрелки/WASD, свайпы и экранные кнопки. Пробел — старт/пауза, R — заново, M — звук.

Три уровня сложности. Рекорды сохраняются, если хранилище браузера доступно. Рассчитано на актуальные Chrome, Edge, Firefox и Safari. Внешние шрифты необязательны. Можно скачать index.html и открыть локально.

Проверка: `node check.mjs`. GitHub Actions проверяет игру и публикует index.html после обновления main. В Settings → Pages источник: GitHub Actions.

Файлы *_diff.* — архивные материалы; релиз использует корневой index.html.
