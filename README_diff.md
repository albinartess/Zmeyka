# 🐍 Змейка — аркадная браузерная игра

![React](https://img.shields.io/badge/React-18-149eca) ![TypeScript](https://img.shields.io/badge/TypeScript-5.7-3178c6) ![Vite](https://img.shields.io/badge/Vite-6-646cff) ![Tailwind](https://img.shields.io/badge/Tailwind-4-38bdf8)

Современная версия классики в неоновом «аркадном» стиле. Игровое поле отрисовывается на Canvas с интерполяцией движения — змейка скользит плавно при стабильных 60 FPS. Полная поддержка клавиатуры и сенсорных экранов.

## Возможности

- **Плавное движение** — интерполяция между клетками, скруглённое градиентное тело, моргающая голова
- **Сочная обратная связь** — частицы, расходящиеся круги, всплывающие «+10 / +50», тряска экрана и вспышка при столкновении
- **Управление** — стрелки / WASD / свайпы / экранный D-pad на мобильных
- **Пауза** — пробел, Esc или P; автопауза при сворачивании вкладки
- **Три уровня сложности** — скорость нарастает с каждым яблоком, интервал тика от 165 до 50 мс
- **Бонусная звезда** — появляется каждые 5 яблок, даёт +50 очков, исчезает через 6,5 с
- **Рекорды** — сохраняются в `localStorage` отдельно для каждого уровня сложности
- **Звук** — синтезированные сигналы через WebAudio (без файлов), отключаются одной кнопкой
- **Адаптивность** — аккуратно выглядит на телефоне, планшете и десктопе

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `↑ ↓ ← →` или `W A S D` |
| Пауза / продолжить | `Пробел`, `Esc` или `P` |
| Перезапуск | `R` (или `Пробел` на экране проигрыша) |
| Меню | `Esc` на экране проигрыша |
| На мобильных | свайпы по полю или экранный D-pad |

## Сложность

| Уровень | Старт | Предел | Разгон за яблоко |
| --- | --- | --- | --- |
| Лёгкий | 165 мс | 100 мс | −3 мс |
| Средний | 118 мс | 68 мс | −2,4 мс |
| Сложный | 86 мс | 50 мс | −1,8 мс |

Очки: яблоко **+10**, бонусная звезда **+50**.

## Технологии

- **React 18 + TypeScript** — состояние и оверлеи
- **Vite 6** — сборка и dev-сервер
- **Tailwind CSS 4** — оформление интерфейса
- **Canvas 2D** — игровое поле и эффекты, `requestAnimationFrame`-цикл с фиксированным шагом логики

## Структура

```
src/
├── App.tsx                  — страница: фон, шапка, панель настроек
├── components/
│   ├── SnakeGame.tsx        — игровой цикл, ввод, HUD, оверлеи
│   └── icons.tsx            — собственные SVG-иконки
└── game/
    ├── core.ts              — правила, сложность, рекорды, эффекты
    ├── draw.ts              — отрисовка Canvas (интерполяция, частицы)
    └── sound.ts             — WebAudio-синтезатор сигналов
```

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка в dist/
```

## Публикация

### GitHub Pages (автоматически)

В репозиторий добавлен workflow `.github/workflows/deploy.yml`: каждый пуш в `main` собирает проект и публикует его на Pages.

1. В настройках репозитория откройте **Settings → Pages** и выберите **Source: GitHub Actions**.
2. Сделайте пуш в `main` — через 1–2 минуты игра будет доступна по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Сборка использует `vite build --base=./`, поэтому работает с любым именем репозитория без правок конфигурации.

### Вручную (без Actions)

```bash
npx vite build --base=./
npx gh-pages -d dist
```
